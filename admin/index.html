السلة وإضافات الهدايا (Cart & Gift Extras)

كل ما يظهر في cart.html يُدار من هنا: نصوص السلة، بطاقات الإهداء، الرسائل المقترحة، واللمسة الأخيرة.

1

نصوص وخيارات صفحة السلة

عنوان الصفحة، سعر وعناوين Photo Stick-In، أكواد الخصم، إظهار/إخفاء الأقسام. (site_settings بالبادئة cart_)

أكواد الخصم تُحسب في المتصفح للعرض فقط. يجب إعادة التحقق من الكود والسعر ورسوم الإضافات داخل checkout / قاعدة البيانات قبل اعتماد الطلب.

3

نافذة الرسالة والتوقيع والرسائل المقترحة

تحكم في أزرار النافذة وأدر عبارات الإهداء الجاهزة حسب المناسبة واللغة.

تغييرات غير محفوظة
تفعيل زر الرسائل المقترحة (Try a Suggested Message)
يفتح نافذة المناسبات والرسائل الجاهزة باللغتين EN / AR.
تفعيل زر التوقيع (Add Signature — رسم أو نص)
يسمح للعميل برسم توقيعه أو كتابته بخط أنيق.
تفعيل إرفاق رابط فيديو أو صورة (Attach a Web Link)
يفتح نافذة Add a Video or Photo لإرفاق رابط مع QR.
إدارة الرسائل المقترحة
عرض/تحرير JSON الكامل (متقدم) صالح

الشكل: { "occasion_key": { "label": "Name", "EN": ["..."], "AR": ["..."] } }. لا يمكن الحفظ إذا كان JSON غير صالح.

4

اللمسة الأخيرة في السلة (Finishing Touch)

عند ربط منتج واحد على الأقل تعرض السلة المنتجات المربوطة فقط (حسب التبويب). وإذا لم يوجد أي ربط تعود السلة للقائمة التلقائية.
